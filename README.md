# 空间视图

一个使用 Rust 和 egui 编写的 Windows 文件夹空间分析工具。选择文件夹后，后台扫描并展示文件和文件夹的大小、占比和空间分布。

- 扫描完成后默认显示大面积“空间地图”。矩形采用方形化树图布局，文件夹按层级分组；面积表示逻辑大小，颜色按绝对大小从绿色到红色分档，灰色表示合并项目。界面和交互参考了 [TreeMap Disk Visualizer](https://github.com/Prithvi-Web/TreeMap-Disk-Visualizer)。
- 地图上单击文件夹进入、单击文件选中；右键可定位到所在目录、复制路径或在资源管理器中查看。悬停可查看完整路径和大小。切换到“目录浏览”可搜索和排序当前目录，列表中单击选中、双击文件夹进入，并可使用右键或右侧操作。
- 为保持大目录下的响应速度，地图最多显示当前目录中最大的 64 个有大小项目；足够大的文件夹会展开其最大的 32 个有大小子项。其余有大小项目合并为灰色“其他项目”，过小的图块可能无法点选；零大小项目没有面积。这些项目均可进入相应文件夹，在“目录浏览”中查看。
- “全局大文件”按逻辑大小展示整个扫描范围内最大的 100 个文件，列出文件名和相对目录；双击或使用右侧操作可定位到文件所在目录，也可复制路径或在资源管理器中查看。右侧同时显示扫描概览和所选项目操作。
- 扫描概览显示根目录、已统计文件数量和逻辑大小、跳过的链接及特殊目录数量，以及读取失败或无法统计的数量。点击读取错误可查看详情，最多保留前 50 条；超过上限时仍显示全部错误数量。
- 默认使用浅色主题；可即时切换深色主题，选择仅在本次运行期间保留。
- 使用“上一级”、面包屑、Backspace 或 Alt+左方向键返回；支持搜索当前目录和按大小、名称排序。
- 扫描时可取消或选择另一个文件夹；程序会等待当前扫描线程退出后，才显示取消完成或开始新的扫描。正在进行的文件系统操作无法强行中断，遇到慢速或无响应的磁盘时可能需要等待。
- 后台扫描线程异常退出时会显示错误，可重新选择文件夹或重新扫描。

## 运行

安装 [Rust](https://rustup.rs/) 和 Windows C++ 构建工具，然后在本目录运行：

```powershell
cargo run --release
```

生成的程序位于 `target\release\disk-insight.exe`，可直接运行。程序会优先使用 Windows 自带的微软雅黑显示中文。

也可以将要扫描的文件夹作为启动参数，例如 `disk-insight.exe "D:\Downloads"`。

## 统计口径

- 大小为成功统计到的普通文件的**逻辑大小**之和，不是 NTFS 实际分配空间、磁盘总已用空间或可释放空间；压缩、稀疏文件、硬链接等可能导致数值不同。
- 不跟随符号链接、目录联接点及其他 Windows 特殊目录，避免循环扫描和重复遍历；所选根目录本身也不能是链接或特殊目录。无法访问或无法统计的项目会计入错误，跳过项及错误意味着结果不包含这些项目。文件类型的非链接重解析点按元数据统计；扫描结果可能随文件变化而变化。
- 全局大文件排行覆盖扫描根目录下成功统计到的普通文件，仅保留最大的 100 项；相同大小的文件在不同扫描中的先后顺序可能不同。
- 空间图及目录列表中的占比相对于当前打开目录中成功统计到的文件总大小。地图中文件夹的外框按其总大小分配面积，展开后其内部内容区域按子项大小再次分配；目录标题、边距和绘制精度会影响可见色块面积。搜索仅过滤列表，不改变地图或分母。
- 扫描结果保存每个项目的名称、父子关系及统计信息，按需还原完整路径；内存占用仍随项目数量增长。当前目录的排序列表也需要额外内存，地图缓存只保存各层限额内的项目。
