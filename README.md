# 空间视图

一个使用 Rust 和 egui 编写的 Windows 文件夹空间分析工具。选择文件夹后，后台扫描并展示文件和文件夹的大小、占比和空间分布。

- 点击空间分布图中的文件夹进入；列表中单击选中，双击文件夹进入，右键可以复制路径或在资源管理器中查看。
- 使用“上一级”、面包屑、Backspace 或 Alt+左方向键返回；支持搜索当前目录和按大小、名称排序。
- 底部状态栏分别显示跳过的链接及特殊目录、读取失败项目。将鼠标放在状态文字上可以查看首个读取错误。

## 运行

安装 [Rust](https://rustup.rs/) 和 Windows C++ 构建工具，然后在本目录运行：

```powershell
cargo run --release
```

生成的程序位于 `target\release\disk-insight.exe`，可直接运行。程序会优先使用 Windows 自带的微软雅黑显示中文。

也可以将要扫描的文件夹作为启动参数，例如 `disk-insight.exe "D:\Downloads"`。

## 统计口径

- 大小为文件的**逻辑大小**之和，不是 NTFS 实际分配空间；压缩、稀疏文件、硬链接等可能导致二者不同。
- 不跟随符号链接、目录联接点及其他 Windows 特殊目录，避免循环扫描和重复遍历；无法访问的项目会计入读取错误。文件类型的非链接重解析点按元数据统计。扫描结果可能随文件变化而变化。
- 占比相对于当前打开目录中成功扫描到的文件总大小。搜索仅过滤列表，不改变分母。
